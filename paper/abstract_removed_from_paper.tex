Deploying deep reinforcement learning (RL) policies trained in simulation onto low-cost microcontroller robots (e.g., ESP32) still relies on brittle, hand-written firmware translation. We present \texttt{simtoreal}, an open-source framework that extracts trained Stable-Baselines3/PyTorch actors and generates precompiled MicroPython bytecode (default) or a zero-dependency, heap-free C header, together with the on-board control loop generated from a YAML hardware description. We validate it on \textit{Robo1}, a 94.8\,g, 2-DOF self-righting robot with a CAD-grounded MuJoCo twin, using an automated verification suite. The generated MicroPython and C code reproduce the PyTorch actor to within $3\times10^{-6}$ on 4{,}609 inputs; driving 1{,}000 simulated episodes with the generated C code reproduces the policy's \SI{97.2}{\percent} get-up success exactly under both nominal and randomized physics; and on a physical ESP32 the generated MicroPython module matches PyTorch to within $9.5\times10^{-7}$. On-device profiling also exposes its limits: the MicroPython backend occupies \SI{119.6}{\kilo\byte} (72\% of the heap) and needs \SI{155}{\milli\second} per inference, $7.8\times$ the \SI{20}{\milli\second} control period; in the full hardware loop (IMU, policy, two servos) sensing and actuation take only \SI{4.2}{\milli\second}, so the network is the sole bottleneck. The suite also exposed defects in the C generator and in the control-loop generator; after fixing both, the generated control loop runs unchanged on the ESP32. Physical self-righting trials are pending.

my project is about the simulation to real robot framework for the resource constrained microcontroller not for any well resourced ros developable controllers,

so currently we train the robo in the simulation and after we write code to change the trainned data into esp32 readable and small in size format 
what we done is a automated platform for translating the trainned data into esp32 readable and small in size format so the trainned data .zip (using the SB3) python package or .pt(using pytorch) converted automatically into .h(C header) or python file or .mpy (binary format) 
and the user will write a config file .yaml file which are the sensors and the actuators they used and the connected pins so that our library will generate the sensor and the actuator class files and the main.py that connects the sensors actuaters and the policy_network so that will be uploaded to the robot easily now using the library user wants to just to make the config once and whenever they want they will change the physics vaiable and train the simulated robot and then give the trainned file (.zip or .pt) after that will be converted by the library and the user will upload it directly this is how the workflow is done
